# Лендинг «Исследования по ОМС» — правки по замечаниям

Исходник страницы https://genomed.ru/about/oms/ и превью правок.

## Файлы

| Файл | Что это |
|---|---|
| `block.html` | **Источник правды.** Ровно тот код, который вставляется в виджет HTML на странице `/about/oms/` |
| `index.html` | Превью для GitHub Pages, собирается из `block.html` |
| `build.py` | Сборка превью: `python3 build.py` |
| `test.js` | Проверки фильтра и поиска: `node test.js` |

## Что изменилось

**1. В первом экране — типы опухоли вместо методов.**
Вместо чипов «NGS · FISH · ПЦР · Иммуногистохимия» — 12 локализаций
(молочная железа, лёгкое, ЖКТ, яичники и матка, меланома, саркомы, ГИСО,
простата, щитовидная железа, мочевой пузырь и почки, опухоли мозга, детские опухоли).
Клик по локализации прокручивает к перечню и фильтрует его.
Рядом кнопка **«Все исследования — весь перечень»**.
Методы никуда не делись — остались фильтром в самой таблице.

**2. Поиск по генам.**
У каждого исследования появился список генов — он же виден в таблице
маленькими плашками, и по нему работает поиск. Учтены синонимы, которыми
пишут в направлениях: `HER2 = ERBB2`, `PD-L1 = PDL1 = CD274`, `CKIT = KIT = CD117`,
`MSI = MMR = MLH1/MSH2/MSH6/PMS2`, `SYT = SS18`, `NMYC = MYCN` и другие.
Пробелы и дефисы в запросе игнорируются: `palb 2`, `PALB-2` и `PALB2` — одно и то же.
Ищется также по коду (`1463`), названию, методу и типу опухоли (`РМЖ`, `кишечник`).

**3. Пустой результат больше не тупик.**
Вместо «ничего не нашлось» — объяснение, что исследование может называться
иначе, чем в направлении, кнопка «Показать все исследования» и телефон.
